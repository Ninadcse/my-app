About these reports

Understand the demo data before using this for real business.

This is a front-end starter version of Dokan Manager BD. Records you add are saved in this browser on this device. They do not sync to another device and are not backed up to a server. The dashboard begins with sample transactions for demonstration. Replace the sample data and add secure authentication, a database and backups before using it for sensitive or mission-critical business records.
